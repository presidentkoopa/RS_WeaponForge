# RULINGS.txt -- BD22. One line per gun: the class, then why it has no magazine
# the reload system can take. set_gate refuses a gun that cannot be reloaded and
# has no ruling, which is right: an unreloadable gun is usually a carve nobody
# did, not a decision.
#
# Each line below says which it is.

# ---- LOADS ROUNDS, AND ITS STORE IS NOT EMITTED YET -----------------------
# These three do reload, from a tube or a chamber rather than a magazine. The
# shipped BD22 card declares that with `store` and `load` blocks -- a tube for
# the shotgun, chambers for the revolver, a chamber for the SSG. The tool does
# not write those blocks yet, so for now these guns ship without their loading
# mechanism and with this ruling instead of a false magazine.
BD_Shotgun    loads from a tube; the store block is not emitted yet
BD_SSG        breaks open and loads two; the store block is not emitted yet
BD_Revolver   loads its chambers; the store block is not emitted yet

# ---- ITS FEED PART IS AN ISLAND NOBODY CAN CUT YET ------------------------
# In the shipped meshes each of these has its magazine or canister cut by hand
# out of the middle of the body surface, and no box reproduces the cut. The gun
# builds and draws whole; it cannot be reloaded until that part can be lifted.
BD_Buzzsaw       its magazine is an uncuttable island inside the body
BD_Machinegun    its magazine is an uncuttable island inside the body
BD_Flamethrower  its canister is an uncuttable island inside the body

# ---- NOTHING IN THE MESH TO RELOAD ---------------------------------------
# One surface, no moving parts: there is no magazine in these meshes to find.
BD_FlameCannon   one surface, no magazine in the mesh
BD_Hellish       one surface, no magazine in the mesh
BD_BFG           two surfaces, a body and a casing: no cell in the mesh to carve
BD_BFG10k        the same mesh as the BFG, and the same absence
